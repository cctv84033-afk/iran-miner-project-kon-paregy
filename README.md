# Iran Miner — بسته مخصوص GitHub Pages

این بسته برای انتشار **نسخه نمایشی استاتیک** در GitHub Pages آماده شده است. در آن Python، FastAPI، SQLite یا ربات تلگرام اجرا نمی‌شود.

## انتشار رایگان در GitHub Pages

1. یک Repository جدید در GitHub بسازید (مثلاً `iran-miner`).
2. فایل ZIP را روی گوشی/کامپیوتر استخراج کنید.
3. **محتویات داخل پوشه** را در ریشه Repository قرار دهید؛ باید `index.html` مستقیماً در صفحه اصلی مخزن دیده شود.
4. تغییرات را با Commit ذخیره کنید.
5. در GitHub وارد `Settings → Pages` شوید.
6. در قسمت **Build and deployment**، گزینه **Source: GitHub Actions** را انتخاب کنید.
7. فایل workflow موجود در `.github/workflows/pages.yml` به‌صورت خودکار سایت را منتشر می‌کند. از تب `Actions` پایان اجرای workflow را بررسی کنید.
8. لینک عمومی معمولاً به شکل `https://USERNAME.github.io/REPOSITORY/` خواهد بود.

اگر repository نام `USERNAME.github.io` داشته باشد، آدرس سایت `https://USERNAME.github.io/` خواهد بود.

## ویدیوی ماینر

ویدیوی خودتان را با نام دقیق `miner.mp4` در کنار `index.html` در ریشه مخزن قرار دهید. مسیر ویدیو در HTML نسبی است و با آدرس پروژه GitHub Pages کار می‌کند. اگر فایل ویدیو بزرگ است، محدودیت‌های GitHub را بررسی کنید و از فایل بسیار حجیم استفاده نکنید.

## محدودیت‌های مهم این نسخه

- این نسخه فقط فرانت‌اند است و برای پیش‌نمایش عمومی طراحی شده.
- ثبت‌نام و ورود فقط به‌صورت نمایشی و با `localStorage` همان مرورگر انجام می‌شود؛ حساب بین دستگاه‌ها یا مرورگرها مشترک نیست.
- رمزها در این نسخه امنیت واقعی ندارند. برای اطلاعات واقعی یا حساس استفاده نکنید.
- هویت Telegram کاربر اعتبارسنجی نمی‌شود؛ `initData` تلگرام بررسی نمی‌شود.
- موجودی، استخراج، دعوت و برداشت همگی شبیه‌سازی‌شده‌اند. هیچ استخراج رمزارز، انتقال بانکی یا انتقال USDT انجام نمی‌شود.
- تغییر وضعیت برداشت به «واریز شد (نمایشی)» پس از ۴۸ ساعت فقط در همان مرورگر و بر اساس ساعت دستگاه است و پرداخت واقعی نیست.
- ربات تلگرام و فایل‌های Python در GitHub Pages اجرا نمی‌شوند.

برای نسخه واقعی چندکاربره با حساب امن، دیتابیس مرکزی و ربات تلگرام، باید بک‌اند Python روی یک سرویس جداگانه میزبانی شود؛ GitHub Pages به‌تنهایی این امکانات را ارائه نمی‌دهد.
